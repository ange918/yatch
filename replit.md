# Yacht Luxe - Luxury Yacht Rental Website

## Overview

Yacht Luxe is a static luxury yacht rental website built with pure HTML, CSS, and JavaScript. The site showcases a premium yacht rental service with an elegant French interface, featuring fleet displays, booking functionality, pricing tiers, and customer testimonials. The project emphasizes responsive design and smooth user interactions without relying on external frameworks.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Pure HTML/CSS/JavaScript**: No external frameworks or libraries used, ensuring fast loading times and minimal dependencies
- **Responsive Design**: Mobile-first approach with breakpoints for tablet and desktop experiences
- **Component-based Structure**: Modular JavaScript functions for different page sections (header, hero, fleet, testimonials, etc.)
- **CSS Variables**: Centralized color scheme management using CSS custom properties for consistent theming

### Design System
- **Color Palette**: Sophisticated blue-toned palette with five defined color variables ranging from dark navy to light pastels
- **Typography**: Combination of Montserrat (sans-serif) for body text and Playfair Display (serif) for headings
- **Layout Strategy**: CSS Grid and Flexbox for responsive layouts with container-based centering

### Interactive Features
- **Sticky Navigation**: Dynamic header behavior with background opacity changes on scroll
- **Mobile Menu**: Hamburger menu with animated transitions for mobile devices
- **Fleet Modals**: JavaScript-powered modal system for yacht detail views
- **Image Lightbox**: Custom gallery lightbox implementation for photo viewing
- **Testimonial Carousel**: JavaScript slider for customer reviews
- **Form Validation**: Client-side validation for search and contact forms

### User Experience Elements
- **Smooth Scrolling**: Anchor-based navigation with smooth scroll behavior
- **Scroll Animations**: Progressive element reveal animations triggered by viewport intersection
- **Loading States**: Interactive feedback for form submissions and dynamic content
- **Accessibility**: Semantic HTML structure with proper heading hierarchy and navigation landmarks

## External Dependencies

- **Google Fonts**: Montserrat and Playfair Display font families loaded via CDN for enhanced typography
